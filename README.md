# LOCKE PROTOCOL (working title) - Hack'd

A browser hacker game: *Mr. Robot* realism meets 1990s *Hackers* style.
You type **real Linux commands** (`sudo apt update`, `nmap`, `john`, `ssh`, `gpg`...) into a simulated Kali terminal across 5 levels.
Everything is a fictional simulation - no real networks or targets are touched.

- Play: open `index.html` in a browser, or run `python -m http.server` here and visit http://localhost:8000
- Levels and answers: see [LEVELS.md](LEVELS.md)
- Status: prototype (5 levels + finale). Characters are placeholders. A Parker Data Link LLC project.
